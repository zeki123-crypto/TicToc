# 🤖 Деплой TicToc на Bothost.ru (тариф «Базовый», 99₽/мес)

[Bothost.ru](https://bothost.ru) — российский хостинг ботов с автодеплоем из
Git и поддержкой **Docker-контейнеров**.

> **Почему «Базовый», а не Free:** боту нужны переменные окружения для токена
> (на Free они недоступны) и больше памяти для ffmpeg. «Базовый» даёт
> **env-переменные + 1 GB RAM + 5 GB диск** — этого достаточно.
>
> ⭐ **Тип сборки выбирай «Dockerfile»** — наш образ ставит **ffmpeg**, без
> которого не работают уникализация и водяные знаки.

## Шаг 1. Токен бота

В Telegram у **@BotFather**: `/newbot` → скопируй токен `123456789:AA...`.

---

## Шаг 2. Проект на Bothost

1. Войди на https://bothost.ru, открой тариф **Базовый**.
2. Создай проект → **Деплой из Git** → подключи GitHub.
3. Репозиторий **`zeki123-crypto/TicToc`**, ветка
   **`claude/telegram-video-download-bot-gab72t`** (или `main` после мержа).
4. Тип окружения / сборки — **Dockerfile**.

---

## Шаг 3. Переменные окружения

В разделе **Переменные окружения** добавь (на «Базовом» они доступны):

```
BOT_TOKEN=сюда_токен_от_BotFather
STORAGE_TYPE=memory
MAX_CONCURRENT_JOBS=1
MAX_DURATION_SECONDS=600
MAX_FILE_SIZE_MB=50
THROTTLE_RATE=2.0
LOG_LEVEL=INFO
```

Пояснения под ресурсы тарифа (1 GB RAM / 2 vCPU):

| Переменная | Значение | Почему так |
| --- | --- | --- |
| `STORAGE_TYPE` | `memory` | Один экземпляр бота — Redis не нужен, экономим RAM |
| `MAX_CONCURRENT_JOBS` | `1` | Одна ffmpeg-задача за раз → не упираемся в память |
| `MAX_DURATION_SECONDS` | `600` | Ограничиваем длину видео (10 мин) — для TikTok с запасом |
| `MAX_FILE_SIZE_MB` | `50` | Лимит отправки Telegram |

> Если позже захочешь Redis (например, добавишь аддон) — поставь
> `STORAGE_TYPE=redis` и `REDIS_DSN=<url>` (бот также понимает `REDIS_URL`).

---

## Шаг 4. Запуск

1. Сохрани настройки → Bothost соберёт Docker-образ и запустит бота.
2. Открой **Логи**. Должно появиться:

   ```
   storage.memory
   bot.started    username=<твой_бот>  id=...
   ```

3. Открой бота в Telegram, нажми **Start**, кинь ссылку на TikTok 🎉

При каждом `git push` в выбранную ветку Bothost пересоберёт и перезапустит
бота автоматически.

---

## Заметки по ресурсам (важно для 1 GB RAM)

- **Память:** один ffmpeg-процесс на короткий ролик укладывается в лимит.
  `MAX_CONCURRENT_JOBS=1` не даёт нескольким задачам съесть всю RAM.
- **Диск 5 GB:** временные файлы (скачанное + обработанное) удаляются сразу
  после отправки, так что место не копится.
- Если попадётся очень тяжёлое/длинное видео — бот вернёт понятную ошибку
  (лимит длительности / размера), а не «упадёт».

## Частые вопросы

**В логах «ffmpeg is not installed»**
→ Сборка идёт не через Docker. Переключи тип окружения на **Dockerfile**.

**Бот не отвечает, ошибка токена**
→ Проверь `BOT_TOKEN` (целиком, без пробелов) в переменных окружения.

**Видео не отправляется, «слишком большое»**
→ Лимит Telegram 50 МБ. Для TikTok обычно ок.

**Хочу масштабировать / несколько ботов**
→ На «Базовом» до 5 ботов. Для одного бота long-polling держи **один**
экземпляр на токен (иначе конфликт `getUpdates`).
