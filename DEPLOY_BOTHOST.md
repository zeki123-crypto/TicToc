# 🤖 Деплой TicToc на Bothost.ru (тариф «Базовый», 99₽/мес)

[Bothost.ru](https://bothost.ru) — российский хостинг ботов с автодеплоем из
Git. Bothost сам собирает образ по выбранному языку/версии Python.

> **ffmpeg уже включён в зависимости** (`imageio-ffmpeg`), а шрифт для водяных
> знаков лежит в репозитории — поэтому **обработка видео работает прямо в
> авто-сборке Bothost**, отдельный Docker/apt не нужен.
>
> **Почему «Базовый», а не Free:** боту нужны переменные окружения для токена
> (на Free они недоступны) и больше памяти для ffmpeg. «Базовый» даёт
> env-переменные + 1 GB RAM + 5 GB диск.

---

## Как заполнить форму создания бота

Поля из мастера Bothost — по порядку:

| Поле | Что выбрать |
| --- | --- |
| **Платформа** | **Telegram** |
| **Язык разработки** | **Python** |
| **Версия Python** | **3.11 (рекомендуется)** — подходит |
| **Bot Token** | вставь токен от **@BotFather** (`123456789:AA...`) |
| **Локация развёртывания** | **Нидерланды (Амстердам)** — обязательно (для Telegram только она) |
| **Переменные окружения** | добавь переменные из таблицы ниже |

> Поле **Bot Token** отдельное — его в «Переменные окружения» дублировать не
> нужно, Bothost сам прокинет `BOT_TOKEN` в бота.

---

## Переменные окружения

Нажми **«+ Добавить переменную окружения»** и заведи каждую (Ключ → Значение):

| Ключ | Значение |
| --- | --- |
| `STORAGE_TYPE` | `memory` |
| `MAX_CONCURRENT_JOBS` | `1` |
| `MAX_DURATION_SECONDS` | `600` |
| `MAX_FILE_SIZE_MB` | `50` |
| `THROTTLE_RATE` | `2.0` |
| `LOG_LEVEL` | `INFO` |

Зачем такие значения (под 1 GB RAM / 2 vCPU):

- `STORAGE_TYPE=memory` — один экземпляр бота, Redis не нужен, экономим память.
- `MAX_CONCURRENT_JOBS=1` — одна ffmpeg-задача за раз → не упираемся в RAM.
- `MAX_DURATION_SECONDS=600` — ограничение длины видео (10 мин), для TikTok с
  запасом.
- `MAX_FILE_SIZE_MB=50` — лимит отправки Telegram.

> Кнопкой **«Загрузить из файла .env»** можно залить всё разом — просто вставь
> строки `КЛЮЧ=значение` из таблицы.

## Подключение репозитория

В настройках проекта подключи GitHub и выбери:

- репозиторий **`zeki123-crypto/TicToc`**
- ветку **`claude/telegram-video-download-bot-gab72t`** (или `main` после мержа)

Bothost поставит зависимости из `requirements.txt` (включая ffmpeg и Pillow) и
запустит бота командой `python -m app` (есть `Procfile` и `main.py`).

## Запуск и проверка

1. Сохрани → Bothost соберёт и запустит бота.
2. Открой **Логи**. Должно появиться:

   ```
   storage.memory
   bot.started    username=<твой_бот>  id=...
   ```

3. Открой бота в Telegram, нажми **Start**, кинь ссылку на TikTok 🎉

При каждом `git push` в ветку Bothost пересоберёт и перезапустит бота.

## Частые вопросы

**В логах «ffmpeg is not available»**
→ Не установились зависимости. Проверь, что `requirements.txt` подхватился
(там есть `imageio-ffmpeg`). Пересобери проект.

**Бот не отвечает, ошибка токена**
→ Проверь поле **Bot Token** (целиком, без пробелов).

**Видео не отправляется, «слишком большое»**
→ Лимит Telegram 50 МБ. Для TikTok обычно ок.

**Не хватает памяти на длинном видео**
→ Уменьши `MAX_DURATION_SECONDS` (например, `300`) — на 1 GB RAM это надёжнее.
